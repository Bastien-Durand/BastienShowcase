# Book covers

Covers load from Open Library (covers.openlibrary.org). Any book without a cover shows the designed cover instead.

To use your own image for a book, put it in this folder (JPG, about 300×450px) and change that book's `src` in index.html to `assets/books/<file>.jpg`.
Currently using the designed cover: The 6 Disciplines of Strategic Thinking (`the-6-disciplines-of-strategic-thinking.jpg`).
